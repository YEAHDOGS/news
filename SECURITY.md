# Security Policy

## Supported versions

This repo is a static landing page (HTML, CSS, a little JavaScript — no
backend, no database, no dependencies). The `master` branch, which is what
GitHub Pages deploys, is the only supported version.

## Reporting a vulnerability

Open an issue at <https://github.com/YEAHDOGS/news/issues> describing the
problem and how to reproduce it. Please don't include personal data in the
report.

Because the site is fully static, the realistic attack surface is small:
defaced content via a compromised deploy, or a malicious link in page copy.
Reports about the absence of a backend feature (there is no backend) or about
third-party infrastructure (GitHub Pages, Cloudflare, Google Fonts) are out
of scope — those belong to the respective providers.
